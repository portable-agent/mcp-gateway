# Карточка MCP Gateway

Этот файл — короткая память для людей и AI-агентов. Обновляй его при изменении границ сервиса.

| Поле               | Значение                                                                 |
| ------------------ | ------------------------------------------------------------------------ |
| Ответственность    | Проверить и направить разрешённый вызов в выбранный MCP-сервис           |
| Владелец           | `portable-agent/backend`                                                 |
| Язык               | TypeScript, Node.js 24                                                   |
| Входящий контракт  | `POST /api/v1/calls`, MCP Gateway API в `portable-agent/contracts`       |
| Исходящий контракт | MCP Streamable HTTP, `tools/call`                                        |
| Свои данные        | Нет постоянного хранилища; сервис stateless                              |
| Прямые зависимости | OIDC JWKS и настроенные MCP-сервисы                                      |
| Не отвечает за     | Решение о выполнении, approval, workflow, UI и бизнес-правила коннектора |
| SLO                | Не определён до сквозного baseline-теста                                 |

## Безопасные границы

- URL и список tools приходят только из конфигурации запуска, не из HTTP-запроса.
- `tenant_id` приходит только из проверенного JWT.
- Ответы провайдера и токены не пишутся в обычные логи.
- Gateway не делает автоматический retry изменяющего tool: повторы контролирует durable workflow, а
  коннектор защищает `requestKey`.
