# MCP Gateway

Gateway изолирует workflow от деталей MCP transport и адресов коннекторов. Первый разрешённый маршрут
ведёт к `fake-calendar`, но адрес и список tools задаются окружением.

Текущее состояние — рабочий stateless-каркас. Он проверяет JWT, allowlist и вызывает MCP. Подключение к
Temporal worker и сквозной тест выполняются следующим изменением после публикации контракта.
